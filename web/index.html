Parameters

Changes apply as the crystal grows, except vapor density and grid size, which apply on restart.

The model is from J. Gravner and D. Griffeath, “Modeling snow crystal growth II: A mesoscopic lattice map with plausible dynamics”, Physica D 237, 385 (2008). It runs here in the snowflakes Python package, with Pyodide.
